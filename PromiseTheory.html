Promise JavaScript/Node.js mein asynchronous operation ka future result represent karta hai. Promise ki 3 states hoti hain: Pending → operation chal raha hai Fulfilled → operation successful Rejected → operation fail Simple Example const promise = new Promise((resolve, reject) => { let success = true; if (success) { resolve("Data mil gaya"); } else { reject("Error aa gaya"); } }); promise .then((result) => { console.log(result); }) .catch((error) => { console.log(error); }); Yahan kya ho raha hai? new Promise() → Promise create karta hai resolve() → Success reject() → Failure .then() → Success ka result handle karta hai .catch() → Error handle karta hai 🎯 Simple Definition Promise ek object hai jo batata hai ki asynchronous operation future mein successful hoga ya fail.
